# 🚀 Minha Jornada no C# e .NET

Bem-vindo ao meu repositório de evolução! Aqui guardo todos os projetos, exercícios e desafios que desenvolvo enquanto estudo lógica de programação e arquitetura backend com C#.

## 📈 Minha Linha do Tempo

### 🔹 Semanas 1 a 4: Fundamentos e Lógica Básica
*   **Conceitos aprendidos:** Variáveis, tipos de dados (`string`, `double`, `int`), entrada/saída de dados (`Console.ReadLine`), estruturas de decisão (`if/else`) e tratamento básico de dados.
*   **Projeto em Destaque:** 
    *   [Calculadora de Notas Escolares](./Semana-01-04_Logica-Basica/CalculadoraNotas/) - Um programa de console que calcula médias, valida limites de notas e avalia a situação do aluno com base na nota e frequência.

### 🔹 Semanas 5 a 6: Modularização e Coleções
*   **Conceitos aprendidos:** Funções/Métodos (`static`), passagem de parâmetros, listas dinâmicas (`List<T>`), laços de repetição (`while`, `for`) e validações robustas com `TryParse`.
*   **Projeto em Destaque:**
    *   [Gerenciador de Tarefas Console](./Semana-05-06_Funcoes-e-Colecoes/GerenciadorTarefas/) - Uma aplicação de lista de tarefas (To-Do) dividida em funções específicas para Adicionar, Listar e Remover itens com validação de índices.
